# VKSF Foundation Website

A responsive static website starter for Vishwakalyan Shanti Foundation (VKSF).

## Deploy on Netlify
1. Extract this ZIP file.
2. Upload the contents of this folder to a GitHub repository (not the ZIP file itself).
3. In Netlify, choose **Add new project → Import an existing project → GitHub**.
4. Select the repository.
5. Build command: leave blank. Publish directory: `.` (the repository root).
6. Deploy.

## Before publishing
- Replace placeholder gallery tiles with approved foundation photos/videos.
- Add the official foundation email in `script.js` (`officialEmail`).
- Connect a trusted donation/payment provider before accepting donations. The current donation section is informational only; it does not collect payments.
- Confirm all 25 community names and descriptions with the foundation.
- Add official address, phone number, social links, privacy policy and terms as applicable.

This is a static front-end starter. It does not include a database, admin dashboard, secure donation processing, member accounts, or media upload backend.
